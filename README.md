# ShikshaFlow AI

An AI-powered educational platform built with **React**, **FastAPI**, and **IBM Granite** (via `ibm-watsonx-ai`).

Teachers manage classes, assign tasks, and get AI-driven insights. Students follow personalised learning paths generated by IBM Granite.

---

## Quick start

### 1. Backend

```bash
cd backend
python -m venv venv
venv\Scripts\activate          # Windows
pip install -r requirements.txt

# Copy and fill in your IBM credentials
cp .env.example .env

# Create the database and run the server
python seed.py                 # creates shikshaflow.db with demo data
uvicorn main:app --reload --port 8000
```

### 2. Frontend

```bash
cd frontend
npm install
npm run dev                    # starts on http://localhost:5173
```

The frontend proxies `/api` → `http://localhost:8000` (configured in `vite.config.js`).

## Environment variables

Create `backend/.env` from `backend/.env.example`:

```env
IBM_API_KEY=your_ibm_cloud_api_key
IBM_PROJECT_ID=your_watsonx_project_id
IBM_MODEL_ID=ibm/granite-13b-instruct-v2
IBM_API_URL=https://us-south.ml.cloud.ibm.com
SECRET_KEY=change_this_to_a_random_string
```

The system degrades gracefully when `IBM_API_KEY` is not set:
- AI chat returns a 503 with a clear message
- Recommendations fall back to rule-based suggestions from topic performance data
- MCQ/True-False scoring always works (deterministic, no AI needed)

## Key design decisions

| Decision | Rationale |
|---|---|
| SQLite + `create_all()` | Zero-config for dev/demo; swap to Postgres for production |
| MCQ/True-False scored in Python | Deterministic; never trust an LLM to do arithmetic |
| Teacher must approve AI tasks | AI never auto-assigns to students |
| At-risk = support signal | Algorithm flags, teacher decides — no automatic labels |
| Granite via f-string prompts | No LangChain overhead; full control over token usage |
| AI degrades gracefully | All non-AI features work without IBM credentials |

## API overview

| Method | Path | Description |
|--------|------|-------------|
| POST | `/auth/register` | Register teacher or student |
| POST | `/auth/login` | Login, returns JWT |
| GET | `/dashboard/teacher` | Aggregated teacher stats |
| GET | `/dashboard/student` | Student streak, tasks, recommendations |
| GET/POST | `/classes/*` | Class CRUD, join by code |
| GET/POST | `/tasks/*` | Task CRUD, approve, submit |
| GET/POST | `/assessments/*` | Assessment CRUD, submit |
| GET/POST | `/attendance/*` | Mark/view attendance |
| GET | `/analytics/class/{id}` | Class analytics + at-risk list |
| GET | `/analytics/student/{id}/class/{id}` | Student topic breakdown |
| POST | `/ai/chat` | Teacher assistant (class-aware) |
| POST | `/ai/generate-task` | AI task generation (draft) |
| POST | `/ai/evaluate-submission` | Grade short-answer questions |
| POST | `/ai/recommend` | Personalised learning path |
| POST | `/ai/suggest-remedial` | Remedial task suggestion for weak topic |
| GET | `/ai/status` | AI service health |
